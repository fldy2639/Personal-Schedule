# v3.2.0 版本说明

**发布日期**：2026-08-07
**基于**：v3.1.0
**schemaVersion**：3（不变，reflection 字段自动迁移）

## 一、项目管理增强

### 背景
旧版项目的积累是隐式的——每次输入新名称自动创建项目记录，但没有可见的项目列表、没有重命名/删除入口。任务中的"所属项目"每次都是纯文本输入，不能从已有项目中选取。

### 变更

**新增项目管理弹窗**
- header 新增「📂 管理项目」按钮
- 弹窗展示所有已有项目，每项显示：名称（可点击编辑）、今日引用次数、删除按钮
- 顶部提供「添加项目」输入框，支持回车快速添加
- 删除时如果有引用记录会提示引用数，确认后执行；被删除项目在引用处显示「（已删除）」

**任务项目选择器**
- 今日主线的「所属项目」从纯文本输入改为下拉选择 + 新建组合
- 下拉列出所有已保存项目，选择「+ 新建项目」时显示输入框
- 旁边提供 ⚙ 按钮可随时打开项目管理弹窗

**工作块弹窗项目选择器**
- 同样新增 ⚙ 管理按钮，与任务侧保持一致

**技术细节**
- 项目数据存储在 `localStorage` 的 `researchScheduleV3Settings` 键（新增 `projects` 数组）
- `getProjectName()` 对孤立 ID 返回 `id + '（已删除）'`
- `countProjectUsage()` 统计当前日内该项目的引用次数

## 二、每日回顾重设计（方案 A）

### 背景
旧版"工作块回顾"区的 5 个问题（什么变清楚了、什么耗时无证据、何时分心、明天接什么、补充笔记）过于抽象和内省，用户反馈使用率低，需要替换为以"产出"为中心的结构化回顾。

### 旧字段（v3.0–v3.1）→ 新字段（v3.2）

| 旧字段 | 新字段 | 说明 |
|--------|--------|------|
| clarified | keyOutputs | 聚焦为"今日关键产出（1—3 条）" |
| timeWithoutEvidence | stuckOrDropped | 重构为"被卡住或搁置的事" |
| mainDistractionMoment | — | 移除，太模糊 |
| tomorrowEntry | tomorrowPriority | 保留并强化为"明天优先级" |
| extraNotes | extraNotes | 保留"自由笔记" |

### 新增：从闭环块导入
- 在「今日关键产出」上方自动显示今日已闭环工作块的 chip（绿色）
- 点击 chip 将该块的证据（或标题）追加到产出文本框
- chip 随工作块的新增/闭环实时更新

### 数据迁移
- `migrateReflection()` 自动将旧字段映射到新字段
- `clarified` 内容合并到 `keyOutputs`，`timeWithoutEvidence` → `stuckOrDropped`，`tomorrowEntry` → `tomorrowPriority`
- Markdown 导出同步更新为新结构

## 三、完整变更列表

### 新增
- 项目管理弹窗：查看 / 添加 / 重命名 / 删除项目
- 任务与工作块的项目选择器统一为下拉 + 新建 + 管理按钮
- 每日回顾：从闭环块导入产出的 chip 组件
- `migrateReflection()` 数据迁移函数
- `countProjectUsage()` 项目引用计数
- `renderKeyOutputChips()` 闭环块 chip 渲染

### 变更
- 每日回顾区域从 5 问替换为 4 项（方案 A）
- `renderTasks()` 中项目字段从纯文本输入改为 `taskProjectHtml()` 选择器
- `renderProjectSelect()` 增加管理按钮
- `getProjectName()` 对已删除项目返回 `（已删除）` 标记
- `renderAll()` 每次刷新同步更新产出 chip
- Markdown 导出「复盘」→「每日回顾」并更新字段

### 移除
- 旧版 5 条复盘问题（已迁移）
- 任务中项目字段的裸文本输入（改为选择器）
