# 更新日志

本项目所有版本的主要变更记录。版本号遵循语义化版本（主版本.次版本.修订号）的精神。

## [v3.2.0] - 2026-08-07

### 新增
- **项目管理弹窗**：header 新增「📂 管理项目」按钮，可查看、添加、重命名、删除项目，显示引用次数
- **书架管理**：与项目管理相同逻辑的书架弹窗（📚），阅读区书名可从书架下拉选取
- **任务项目选择器**：今日主线"所属项目"从纯文本输入改为下拉选择 + 新建 + ⚙ 管理按钮
- **工作指数**：今日所有 30min 段专注分总和（绝对值），与专注指数（百分比）互补
- **从闭环块导入产出**：每日回顾的「今日关键产出」上方自动显示已闭环工作块 chip（绿色），点击即可导入
- **睡眠评价**：睡眠质量下方新增可选文本输入

### 变更
- **每日回顾重设计（方案 A）**：旧 5 问替换为「今日关键产出 / 被卡住或搁置的事 / 明天优先级 / 自由笔记」4 项
- **指标区精简**：HTML 仅显示「工作指数 / 总工作时长 / 深度工作时长 / 工作闭环数量」4 项，其余指标保留在 Markdown 导出中
- 「科研闭环」更名为「工作闭环数量」
- 阅读「页数」改为自由填空「章节数」
- 工作块弹窗项目选择器同步增加管理按钮
- `getProjectName()` 对已删除项目返回 `（已删除）` 标记
- Markdown 导出「复盘」→「每日回顾」，字段同步更新

### 移除
- 旧 5 条复盘问题（`clarified` / `timeWithoutEvidence` / `mainDistractionMoment` 等已在加载时自动迁移）
- HTML 指标区的高质量工作时长、专注指数、推进指数、闭环率、阶段节点等（仅 MD 保留）

### 技术
- 项目列表与书架分别持久化至 `researchScheduleV3Settings`，跨天复用
- 新增 `migrateReflection()` / `migrateLife()` 自动迁移旧数据
- 旧 `reading.pages` 自动转为 `reading.chapters`

### 技术
- 项目列表持久化至 `researchScheduleV3Settings.projects`，跨天复用
- 新增 `migrateReflection()` 自动将旧版 reflection 字段映射至新版
- `renderAll()` 每次刷新同步更新产出 chip

## [v3.1.0] - 2026-07-25

### 新增
- **30 分钟子时段**：工作块内自动按 30min 切分，每段独立评专注（0–4）；推进仍块级评一次
- **半点时间**：工作块开始/结束限制为 :00 / :30（睡眠时间为任意分钟）
- **完成回顾**：子时段列表 + 批量设置（第 N–M 段设为 X）；保留「整体专注」作未评子段默认值
- **指标重算**：深度工作、专注指数等按子段累计；推进指数仍按块级

### 变更
- 睡眠模块：移除「目标入睡」及达标提示，新增「睡眠质量（1—5）」
- `schemaVersion` 升级为 3；旧 v2 数据自动拆段并继承块级专注分

## [v3.0.0] - 2026-07-25

### 重构（科研日程记录表 V2 开发文档 · 阶段一+二）
- **四区布局**：左上时间记录、右上今日主线、左下结构化复盘、右下指标与生活状态
- **工作块模型**：问题 → 行动 → 证据 → 下一步；专注/推进 0—4 分独立评分，二维色条（蓝=专注，橙=推进）
- **今日主线**：核心问题 1 个 + 关键任务最多 3 个，替代旧版无限待办
- **新指标体系**：深度工作、高质量工作、专注/推进指数、闭环率、主线一致度等；移除人生密度、总得分、专注密度（旧算法）
- **生活状态**：睡眠（含目标入睡）、运动、阅读、精力/心情独立记录，不计入科研总分
- **项目混合管理**：全局项目列表 + 可临时新建
- **旧数据迁移**：schemaVersion=2；保留时间段与 legacy 字段，不自动推断专注/推进分
- **Markdown 导出**：新版 YAML frontmatter，适配 Obsidian / Cursor 分析

### 移除
- 10 个快速标签、人生密度得分模块、四类工作时长（事务/高效/低效/摸鱼）

### 暂未实现（阶段三）
- 手机状态与分心触发、复位记录、周/月度聚合

## [v2.2.0] - 2026-06-06

### 新增
- 工作时长新增「低效工作」（边写代码边刷手机），与事务性工作 / 高效工作 / 摸鱼并列
- 新增「专注密度」指标：`专注密度 = 高效工作时长 ÷ 总工作时长`，与人生密度一同展示并支持导出

### 优化
- 「有效工作」更名为「高效工作」（仅显示名变更，不影响已存数据）
- 总工作时长改为四项之和（事务性 + 高效 + 低效 + 摸鱼），作为人生密度与专注密度的统一分母

### 修复
- 修复时间轴视图显示错乱：切换视图时容器被设为 `display:block` 覆盖了 `flex`，导致刻度列与网格上下堆叠、时间块全挤在底部
- 时间块定位由依赖实测像素（`clientHeight`）改为百分比定位，与左侧刻度共用同一比例，缩放/渲染时机变化都不再错位
- 网格刻度线改为按小时等分（`calc(100%/18)`），与左侧刻度严格对齐
- 移除时间轴底部冗余提示文字（原作为 flex 第三列错位显示）

## [v2.1.0] - 2026-06-06

### 重构
- **人生密度模块全面重构**：从旧版「变强得分 + 吃苦时长（坐班/通勤/家务）」改为基于个人指标体系的新版：
  - 得分模块按「科研 / 实践 / 生活」三类，共 10 项，采用次数制（单项得分 = 今日完成次数 × 分值）
  - 工作时长模块改为「事务性工作 / 有效工作 / 摸鱼」三类
  - 计算公式改为 `人生密度 = 总得分 ÷ 总工作时长`，结果保留 2 位小数
  - 数据结构由 `kuQiangData` 迁移为 `lifeDensityData`（不迁移旧数据，从新版开始记录）

### 优化
- 得分项与工作时长改为「精简主词（大字）+ 修饰说明（灰色小字）」两行排版，一眼可读
- 工作时长模块补充「工作时长」小标题，并与得分项统一灰底卡片样式
- 快速标签由 6 个扩充至 10 个：工作、科研、实践、学习、阅读、运动、休息、社交、日常、其他
- 快速标签排布改为 5×2 网格，文字居中，更整齐美观
- 统一「次」输入框与「小时」输入框宽度

### 修复
- 修复时间块 ID 在 localStorage 反序列化后类型不一致（number/string）导致的更新/删除失效问题
- 修复点击时间块时无法正常打开原生时间选择器、交互被整行重绘打断的问题
- 对动态写入的活动内容等做 HTML 转义，避免特殊字符破坏 DOM
- 睡眠记录的「入睡 / 起床」标签补充 `for` 关联，点击文字即可聚焦输入框
