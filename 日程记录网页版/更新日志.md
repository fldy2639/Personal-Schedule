# 更新日志

本项目所有版本的主要变更记录。版本号遵循语义化版本（主版本.次版本.修订号）的精神。

## [v2.2.0] - 2026-06-06

### 新增
- 工作时长新增「低效工作」（边写代码边刷手机），与事务性工作 / 高效工作 / 摸鱼并列
- 新增「专注密度」指标：`专注密度 = 高效工作时长 ÷ 总工作时长`，与人生密度一同展示并支持导出

### 优化
- 「有效工作」更名为「高效工作」（仅显示名变更，不影响已存数据）
- 总工作时长改为四项之和（事务性 + 高效 + 低效 + 摸鱼），作为人生密度与专注密度的统一分母

### 修复
- 修复时间轴视图显示错乱：切换视图时容器被设为 `display:block` 覆盖了 `flex`，导致刻度列与网格上下堆叠、时间块全挤在底部
- 时间块定位由依赖实测像素（`clientHeight`）改为百分比定位，与左侧刻度共用同一比例，缩放/渲染时机变化都不再错位
- 网格刻度线改为按小时等分（`calc(100%/18)`），与左侧刻度严格对齐
- 移除时间轴底部冗余提示文字（原作为 flex 第三列错位显示）

## [v2.1.0] - 2026-06-06

### 重构
- **人生密度模块全面重构**：从旧版「变强得分 + 吃苦时长（坐班/通勤/家务）」改为基于个人指标体系的新版：
  - 得分模块按「科研 / 实践 / 生活」三类，共 10 项，采用次数制（单项得分 = 今日完成次数 × 分值）
  - 工作时长模块改为「事务性工作 / 有效工作 / 摸鱼」三类
  - 计算公式改为 `人生密度 = 总得分 ÷ 总工作时长`，结果保留 2 位小数
  - 数据结构由 `kuQiangData` 迁移为 `lifeDensityData`（不迁移旧数据，从新版开始记录）

### 优化
- 得分项与工作时长改为「精简主词（大字）+ 修饰说明（灰色小字）」两行排版，一眼可读
- 工作时长模块补充「工作时长」小标题，并与得分项统一灰底卡片样式
- 快速标签由 6 个扩充至 10 个：工作、科研、实践、学习、阅读、运动、休息、社交、日常、其他
- 快速标签排布改为 5×2 网格，文字居中，更整齐美观
- 统一「次」输入框与「小时」输入框宽度

### 修复
- 修复时间块 ID 在 localStorage 反序列化后类型不一致（number/string）导致的更新/删除失效问题
- 修复点击时间块时无法正常打开原生时间选择器、交互被整行重绘打断的问题
- 对动态写入的活动内容等做 HTML 转义，避免特殊字符破坏 DOM
- 睡眠记录的「入睡 / 起床」标签补充 `for` 关联，点击文字即可聚焦输入框
