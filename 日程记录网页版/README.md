# 科研日程记录表 v3.2.0

一个零依赖的单文件 HTML 应用，用于记录每日科研时间安排、工作块回顾、每日复盘和生活状态。所有数据保存在浏览器本地，支持一键导出为 Markdown，方便归档到 Obsidian。

## 功能特点

- **四区布局**
  - **左上：时间记录**——列表视图 / 时间轴视图，添加工作块与非工作块
  - **右上：今日主线**——核心问题（1 个）+ 关键任务（最多 3 个）
  - **左下：每日回顾**——今日关键产出 / 卡住或搁置的事 / 明天优先级 / 自由笔记
  - **右下：指标与生活**——工作指数 / 总工作时长 / 深度工作时长 / 工作闭环数量 + 睡眠 / 运动 / 阅读 / 精力 / 心情

- **工作块系统**
  - 工作块：开始/结束时间、活动名称、所属项目、当前问题、预期/实际证据、下一步
  - 专注评分（0–4）与推进评分（0–4），支持按 30 分钟子时段独立评专注
  - 闭环判断（有证据 + 有下一步即为闭环），主线任务与阶段节点标记

- **工作指数**
  - 每 30 分钟 = 1 单位时间，工作指数 = 今日所有单位时间专注分的总和
  - 衡量"今天投入了多少专注量"，与专注指数（效率百分比）互补

- **项目管理**
  - 全局项目列表（📂 管理项目），支持添加、重命名、删除
  - 工作块与任务均通过下拉选择器选取项目，引用次数实时可见
  - 项目数据跨天缓存，已删除项目在引用处显示「（已删除）」

- **书架管理**
  - 与项目相同的管理逻辑（📚），阅读时从书架下拉选取书目
  - 支持添加、重命名、删除，跨天缓存

- **生活状态记录**：睡眠（时长 + 质量 + 评价）、运动（类型 + 时长）、阅读（时长 + 章节数 + 书名 + 所得）、精力/心情评分

- **数据持久化**：按日期自动保存到浏览器 localStorage，项目与书架列表单独缓存

- **导出 Markdown**：生成带 YAML frontmatter 的 `.md` 文件，兼容 Obsidian，完整指标均在导出中保留

## 使用方法

### 1. 基本使用
1. 双击打开 `日程记录.html`（推荐 Chrome / Firefox / Edge）
2. 页面顶部自动显示当前日期与时间

### 2. 时间记录
- 点击「**+ 添加时间段**」新增非工作块（如吃饭、通勤）
- 点击「**▶ 开始工作块**」打开工作块面板，填写活动、项目、问题、预期证据
- 在列表视图中直接编辑时间块的开始/结束时间与活动
- 点击「**📊 时间轴**」切换到甘特图视图
- 工作块结束后点击「**完成回顾**」填写证据、下一步、专注/推进评分

### 3. 今日主线
- 填写「**核心问题**」：今天最想推进的一件事
- 添加「**关键任务**」（最多 3 个）：项目从下拉列表选取，可标记主线

### 4. 每日回顾
- **今日关键产出**：手写或从上方闭环块 chip 一键导入
- **被卡住或搁置的事**：记录未闭环的块和卡点
- **明天优先级**：明天第一步做什么
- **自由笔记**：任何想记下来的东西

### 5. 管理项目 / 书架
- 点击 header 的「**📂 管理项目**」或阅读区的 ⚙ 按钮管理项目
- 阅读区 ⚙ 按钮管理书架
- 添加 / 重命名 / 删除；项目显示今日引用次数

### 6. 保存与导出
- **保存到本地**：数据自动保存到浏览器 localStorage，也可手动点击保存
- **导出 Markdown**：生成 `每日记录-YYYY-MM-DD.md` 并下载
- **清空今日**：清空当天记录并恢复默认状态

## 与 Obsidian 集成

1. 完成记录后点击「📤 导出 Markdown」
2. 文件下载为 `每日记录-YYYY-MM-DD.md`
3. 将文件复制到 Obsidian vault 的日志目录
4. frontmatter 中的 `work_index`、`focus_index`、`progress_index`、`closure_rate` 等字段可用于检索与图表

## 浏览器兼容性

- **推荐**：Chrome、Edge、Firefox 等现代浏览器
- **要求**：支持 ES6、localStorage、Blob API

## 数据安全

- 所有数据仅存于浏览器本地（localStorage），不上传任何服务器
- 建议定期导出 Markdown 作为备份

## 技术细节

- **形态**：单 HTML 文件，零外部依赖（纯 HTML/CSS/JavaScript）
- **存储**：浏览器 localStorage（约 5MB 限制），按日期分别存储；项目与书架配置存储在独立 key 中
