# 每日效率记录工具 v2.2.0

一个零依赖的单文件 HTML 应用，用于记录每日时间安排、任务、睡眠、笔记，并通过「人生密度」模块量化每日产出。所有数据保存在浏览器本地，支持一键导出为 Markdown，方便归档到 Obsidian。

## 功能特点

- **双视图时间记录**
  - **时间轴视图**：可视化时间块分布，类似甘特图
  - **编辑列表视图**：逐条编辑每个时间段的开始/结束时间与活动内容
- **10 个快速标签**：工作、科研、实践、学习、阅读、运动、休息、社交、日常、其他；5×2 网格排布，颜色编码，点击应用到选中的时间块
- **睡眠记录**：填写入睡/起床时间，自动计算睡眠时长（支持跨午夜）
- **人生密度评估（v2 新版）**：得分模块（科研/实践/生活，次数 × 分值）+ 工作时长模块（事务性/高效/低效/摸鱼），计算「人生密度 = 总得分 ÷ 总工作时长」与「专注密度 = 高效工作时长 ÷ 总工作时长」
- **任务管理**：创建待办，标记完成状态
- **笔记与反思**：自由记录想法、收获、反思
- **数据持久化**：按日期自动保存到浏览器 localStorage
- **导出 Markdown**：生成带 frontmatter 的 `.md` 文件，完美兼容 Obsidian

## 使用方法

### 1. 基本使用
1. 双击打开 `日程记录.html`（推荐 Chrome / Firefox / Edge）
2. 页面顶部自动显示当前日期与时间
3. **时间记录**
   - 点击「时间轴视图 / 列表视图」切换两种视图
   - 列表视图中直接编辑每个时间块的开始/结束时间与活动
   - 点击「添加时间段」新增时间块
4. **快速标签**
   - 先点击选中一个时间块（时间轴上的彩色条或编辑行）
   - 点击下方标签应用到选中的时间块，时间块会变色以便分类
5. **睡眠记录**：填写入睡、起床时间，自动显示睡眠时长
6. **任务 / 笔记**：添加任务、勾选完成；在笔记区记录反思

### 2. 保存与导出
- **保存到本地**：数据保存到浏览器 localStorage（编辑时也会自动保存）
- **导出 Markdown**：生成 `每日记录-YYYY-MM-DD.md` 并下载
- **清空数据**：清空当天记录并恢复默认状态

### 3. 人生密度评估

「人生密度」用于量化单位工作时间内的有效产出，数值越大代表单位时间产出越高。

**得分模块**（每项填写今日完成次数，单项得分 = 次数 × 分值）

- 科研得分
  - 读论文（理解并记录思路）：0.5
  - 记录 idea（能和导师交流的想法）：0.5
  - 推进工作进展（思路推进或跑通代码）：1
- 实践得分
  - 学习新知识（听课看材料并记录所得）：0.5
  - 跑通代码（理解整体架构与关键部分）：0.5
  - 推进简历项目（设计产品或实现功能）：1
  - 主动汇报进展（向导师或上位领导汇报实质性进展）：1
- 生活得分
  - 早睡（0:30 前睡着）：1
  - 运动（任意强度）：0.5
  - 阅读（锻炼到思维）：0.5

**工作时长模块**（小时）

- 事务性工作：兼职、学生工作、日常琐事
- 高效工作：专注看论文、写代码、推项目
- 低效工作：边写代码边刷手机
- 摸鱼：刷手机、游戏、拖延式刷公众号/B站

**计算公式**

```
人生密度 = 总得分 ÷ 总工作时长       （保留 2 位小数）
专注密度 = 高效工作时长 ÷ 总工作时长  （保留 2 位小数）
```

- 总得分 = 各得分项（次数 × 分值）之和
- 总工作时长 = 事务性 + 高效 + 低效 + 摸鱼
- 未填写工作时长时仅显示总得分并提示无法计算密度

## 与 Obsidian 集成

1. 在效率工具中完成记录后点击「导出 Markdown」
2. 文件下载为 `每日记录-YYYY-MM-DD.md`
3. 将文件复制到 Obsidian vault 的日志目录（如 `Daily/2026/06/`）
4. 在 Obsidian 中刷新即可，frontmatter 中的 `tags`、`life_density_index` 等字段可用于检索与图谱

## 导出文件格式示例

```markdown
---
date: 2026-06-06
weekday: 星期六
life_density_index: 0.58
tags: [科研, 实践]
total_time: 7h
---

# 2026-06-06 星期六 每日记录

## ⏰ 时间记录

| 时间 | 活动 | 时长 |
|------|------|------|
| 09:00-12:00 | 看论文 | 3h |
| 13:30-17:30 | 写代码 | 4h |

总计：7小时

## ✅ 今日任务

- ✅ 完成实验脚本
- ⬜ 整理周报

## 😴 睡眠记录

- **入睡时间**: 00:20
- **起床时间**: 07:30
- **睡眠时长**: 7小时10分钟

## 📊 人生密度评估

### 得分明细

#### 科研得分
- 读论文（理解并记录思路）: 2次 × 0.5 = 1.0分
- 推进工作进展（思路推进或跑通代码）: 1次 × 1 = 1.0分

- **总得分**: 2.0分

### 工作时长
- **事务性工作**: 1小时
- **高效工作**: 6小时
- **低效工作**: 1小时
- **摸鱼**: 1小时
- **总工作时长**: 9.0小时

### 人生密度
- **人生密度**: 0.22（总得分 ÷ 总工作时长）
- **专注密度**: 0.67（高效工作时长 ÷ 总工作时长）

## 📝 笔记与反思

今日重点：...

---
*记录时间: 2026/6/6 下午8:00:00*
```

## 浏览器兼容性

- **推荐**：Chrome、Edge、Firefox 等现代浏览器
- **要求**：支持 ES6、localStorage、Blob API、`type="time"` 输入框

## 数据安全

- 所有数据仅存于浏览器本地（localStorage），不上传任何服务器
- 建议定期导出 Markdown 作为备份

## 技术细节

- **形态**：单 HTML 文件，零外部依赖（纯 HTML/CSS/JavaScript）
- **存储**：浏览器 localStorage（约 5MB 限制），按日期分别存储
- **自定义**：得分项与工作时长配置集中在 `日程记录.html` 的 `lifeDensityScoreItems` / `lifeDensityWorkFields`，标签配置在 `getTagColor` / `getTagClassName` 与 `.color-tags`，便于按需修改
